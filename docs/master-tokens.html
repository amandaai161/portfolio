Master tokens

Every colour and type value the site is built from, at the names the CSS actually uses. This page is set in those tokens — each step below renders at its own real value, so what you see is what ships.

One black #111111 everywhere. Not #000, and not a second near-black hiding in a component.
Outline, not fill Containers are paper with a 1.5px black outline. Grey is a fill inside one, never the container itself.
One grey #ECECEC, for a progress track, a filled bar or a nested panel. Nothing else.
Squared corners No radius on containers. --radius-media exists only for imagery.

Master colour

Declared on :root in css/styles.css. Swatches show the literal value, so they read the same in either theme.

--black #111111 The brand black. Ink, outlines, solid fills.
--ink #111111 Body text. Same value as --black, kept separate so text and surface can diverge later.
--white #FFFFFF Paper. The about page softens this to #F8F8F8 for itself only.
--fill-soft #ECECEC The one grey. Progress tracks, filled bars, nested panels.
--line-strong #111111 Structural outline, always 1.5px.
--muted rgba(17, 17, 17, .55) Secondary text, captions, meta.
--line rgba(17, 17, 17, .18) Hairline. Table rows, internal dividers.
--line-light rgba(255, 255, 255, .35) Hairline on the black footer.
Container — paper, 1.5px outline

Solid Reserved for one element per view — a stat card, an active state, the footer.

Desktop and mobile

One breakpoint governs the whole system: 760px. Below it the headings drop to fixed sizes, leading opens up and negative tracking relaxes, because tight tracking hurts legibility at small sizes. Body steps hold at 16px and above so copy never shrinks on a phone.

Weights

Five, and they compose with any role class via the .fw-* helpers. Medium carries the headings; Regular carries the copy; SemiBold is for eyebrows, H6 and emphasis inside a paragraph.

Aa--fw-light300 · rare, large sizes only
Aa--fw-regular400 · body copy
Aa--fw-medium500 · headings, nav, buttons
Aa--fw-semibold600 · eyebrows, H6, emphasis
Aa--fw-bold700 · wordmark only

Role classes

Apply a class rather than reaching for the raw token, so size, weight, leading and tracking always arrive as a set. Read a --fs-* token directly only when you are writing a component's own rule.

Where the tokens live

FileHolds
css/styles.cssColour, layout and motion tokens on :root. The source of truth.
css/type-system.cssThe type scale, the role classes, and the ≤760px retune. Loads after styles.css.
css/master-header.cssThe master header, scoped under .master-header for pages that cannot take the global reset.
css/master-footer.cssThe master footer, scoped under .master-footer, same reason.
scripts/gen-master-chrome.pyGenerates both scoped files from the two above. Regenerate; never hand-edit them.

The one exception. Aspire, Identity, Kayn and NOBI are hand-built landing pages with their own palettes, and these tokens do not reach them. Only the portfolio's own furniture on those pages — the master footer, the-process section, the nav dock and the cursor — follows this system.

Hazen and the seven case-study pages are fully on it.
