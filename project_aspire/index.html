Aspire Web Design System

  • Web Design
  • Web Design System

A comprehensive Figma-to-Webflow design system to replace an inefficient, manual web development workflow. The system standardizes components and organizes assets to enable fast, scalable updates across 120+ pages.

Year
2025
Duration
8 weeks
Company
Aspire
Industry
Fintech

Three key design decisions that shaped the outcome.

  • One component, every page

    Every block on the site resolves to a component with named variants, so a change to a card style lands on all 120+ pages at once instead of being repeated by hand on each of them.

  • Named for whoever ships it

    Layers, variants and assets use the vocabulary the marketing team already speaks, not designer shorthand. A non-designer can find the right block and reuse it without opening a ticket.

  • Built to survive the handoff

    The Figma structure mirrors Webflow’s class and symbol model one to one, so what a designer assembles is what a developer builds. No translation step, and no drift between the file and the live site.
