Aspire Web Design System

A comprehensive Figma-to-Webflow design system to replace an inefficient, manual web development workflow. The system standardizes components and organizes assets to enable fast, scalable updates across 120+ pages.

Year

Duration
8 weeks
Company
Aspire
Industry
Fintech

Key design decisions

  • Started with an audit, not a style guide

    I went through every existing Figma file to find which patterns kept coming back and which were one-offs. The system standardized what the team actually used, not what a template assumed.

  • Matched Figma variables to Webflow classes 1:1

    Every token a designer used had a twin a developer could find by name. Handoff stopped being a translation job, and the repeated errors from unintended changes stopped with it.

  • Made components that sync across sites

    One edit to a component reached every site that used it. That’s what made revamping the whole site realistic rather than a page-by-page slog.
